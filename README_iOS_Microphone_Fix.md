# Решение проблемы с микрофоном на iOS устройствах

## Описание проблемы

После использования miniApp с WebRTC и получения разрешения на использование микрофона в веб-браузере, микрофон в самом Telegram может перестать работать. Пользователь не сможет записать голосовое сообщение, так как микрофон становится недоступным.

## Причины проблемы

1. **WebRTC захватывает аудио сессию**: При использовании WebRTC для аудио, iOS может "захватить" аудио сессию и не освобождать её правильно
2. **Конфликт аудио контекстов**: WebRTC создает свой AudioContext, который может конфликтовать с аудио контекстом Telegram
3. **iOS Safari ограничения**: iOS Safari имеет специфические ограничения по работе с аудио и микрофоном

## Реализованные решения

### 1. Управление аудио сессией iOS

Создан класс `IOSAudioSessionManager` для правильного управления аудио сессией:

- **Активация**: Правильная инициализация аудио контекста для WebRTC
- **Деактивация**: Корректное освобождение всех аудио ресурсов
- **Восстановление**: Принудительное восстановление стандартной аудио сессии iOS

### 2. Автоматическая очистка ресурсов

- Мониторинг состояния аудио сессии
- Автоматическое освобождение при закрытии приложения
- Обработка событий переключения вкладок и скрытия страницы

### 3. Кнопка восстановления микрофона

Добавлена специальная кнопка "🔧 Восстановить микрофон в Telegram" для iOS устройств, которая:

- Принудительно освобождает аудио сессию
- Восстанавливает стандартную аудио сессию iOS
- Показывает инструкции пользователю

### 4. Уведомления и инструкции

Информативные уведомления с пошаговыми инструкциями:

1. Закройте мини-приложение
2. Попробуйте записать голосовое сообщение в Telegram
3. Если не работает, перезапустите Telegram

## Технические детали

### Ключевые функции

```javascript
// Активация аудио сессии для WebRTC
await iosAudioManager.activateAudioSession();

// Деактивация и освобождение ресурсов
await iosAudioManager.deactivateAudioSession();

// Принудительное восстановление стандартной сессии
await iosAudioManager.forceIOSAudioSessionRelease();
```

### Обработка событий

- `beforeunload` - освобождение ресурсов при закрытии страницы
- `pagehide` - освобождение при скрытии страницы
- `visibilitychange` - управление аудио при переключении вкладок
- `devicechange` - мониторинг изменений аудио устройств

### iOS-специфичные настройки

```javascript
// Специальные ограничения для iOS Safari
const iosConstraints = {
  echoCancellation: { ideal: true },
  noiseSuppression: { ideal: true },
  autoGainControl: { ideal: true },
  channelCount: { ideal: 1, max: 1 },
  sampleRate: { ideal: 44100, max: 48000 },
};
```

## Рекомендации для пользователей

### Профилактика

1. **Закрывайте мини-приложение** после использования
2. **Не оставляйте приложение в фоне** на iOS устройствах
3. **Перезапускайте Telegram** при возникновении проблем

### Решение проблем

1. **Используйте кнопку восстановления** в мини-приложении
2. **Закройте и откройте** мини-приложение заново
3. **Перезапустите Telegram** при необходимости
4. **Проверьте настройки** микрофона в iOS

### Настройки iOS

1. **Настройки > Конфиденциальность > Микрофон**
2. Убедитесь, что Telegram имеет разрешение
3. При необходимости отключите и включите разрешение заново

## Тестирование

### Проверка работы

1. Откройте мини-приложение в Telegram
2. Используйте голосовой чат
3. Закройте мини-приложение
4. Попробуйте записать голосовое сообщение в Telegram

### Отладка

В консоли браузера должны появляться логи:

```
iOS Audio Session activated for WebRTC
iOS Audio Session deactivated
Detected orphaned audio session, cleaning up...
```

## Известные ограничения

1. **iOS Safari**: Некоторые проблемы могут быть связаны с ограничениями самого браузера
2. **Версии iOS**: Поведение может отличаться в разных версиях iOS
3. **Модели устройств**: Некоторые iPhone могут иметь специфические проблемы
